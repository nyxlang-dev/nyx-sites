El módulo std/json provee un parser y constructor de JSON completo. Los valores JSON se representan como nodos Array etiquetados — el primer elemento es la etiqueta de tipo y el segundo es el valor — lo que facilita inspeccionar y recorrer cualquier documento JSON.

Objeto: {"name":"Alice","age":30,"activo":true} Array: [10,20,30] Tipo: number Valor: 42 Array parseado: [1,2,3]

Los valores JSON se construyen con funciones constructoras tipadas: json_string, json_number, json_bool, json_object y json_array. Cada una devuelve un Array etiquetado donde node[0] es el string de tipo (p. ej. "number") y node[1] es el contenido. Esta representación uniforme hace que el recorrido recursivo sea directo.

json_stringify serializa cualquier nodo JSON de vuelta a un string compacto. json_parse hace lo inverso — acepta un string JSON y devuelve la misma estructura de array etiquetado, que luego puedes inspeccionar con json_type o indexar directamente.

Para leer campos anidados, encadenarías indexación de arrays: obj[1][1] llega al primer valor dentro de un nodo de objeto JSON. El próximo ejemplo (16) se enfoca en construir estructuras anidadas complejas para serialización.
