A byte buffer with a raw pointer

To walk many pixels or bytes in a hot loop, an Array pays one runtime call per access. A raw pointer to a scalar (*u8, *int) indexes memory directly: p[i] reads or writes element i, at i * sizeof(T) bytes from the start, as in C. There is no bounds check, so it lives inside unsafe.

// Nyx by Example: un buffer de bytes con un puntero crudo.
//
// Para recorrer muchos píxeles o bytes en un bucle caliente, un `Array`
// paga una llamada al runtime por acceso. Un puntero crudo (`*u8`, `*int`)
// indexa directo en memoria: `p[i]` lee o escribe el elemento i, a
// i * sizeof(T) bytes del inicio, sin chequeo de límites (como en C). Por
// eso vive dentro de `unsafe`.
//
// Un `u8` leído se ensancha SIN signo: 250 sigue siendo 250 al pasarlo a
// int. Y `*p as int` es `(*p) as int`: el `as` se aplica al valor leído.

fn main() -> int {
    unsafe {
        // Una fila de 6 píxeles en escala de grises.
        let fila: *u8 = alloc<u8>(6)
        var i = 0
        while i < 6 {
            fila[i] = 200 + i * 10    // 200, 210, ..., 250
            i = i + 1
        }

        // Invertir cada píxel y sumar el brillo total.
        var total = 0
        i = 0
        while i < 6 {
            let v: int = fila[i] as int
            fila[i] = 255 - v
            total = total + v
            i = i + 1
        }
        println("brillo original: " + int_to_string(total))
        println("primer píxel invertido: " + int_to_string(*fila as int))

        // Lo mismo con enteros de 64 bits.
        var acum: *int = alloc<int>(3)
        acum[0] = 1
        acum[1] = 2
        acum[2] = acum[0] + acum[1]
        println("acum[2] = " + int_to_string(acum[2]))

        free(fila)
        free(acum)
    }
    return 0
}
Outputstdout
brillo original: 1350
primer píxel invertido: 55
acum[2] = 3

How it works

The program reserves a row of 6 grayscale pixels with alloc<u8>(6) and fills it with fila[i] = 200 + i * 10 (200, 210, up to 250). A second loop reads each pixel as an int, writes back 255 - v to invert it and adds up the original brightness, which is 1350. Then it does the same with 64-bit integers: an *int from alloc<int>(3), where acum[2] is the sum of the first two cells. Both buffers are released with free.

Two details worth knowing. A u8 that is read widens without sign: 250 is still 250 when you convert it with as int, never a negative number. And *fila as int means (*fila) as int: the as applies to the value that was read, which is why the first inverted pixel prints 55 (255 - 200).

Limits: the pointer carries no length, so reading or writing past the reserved size is undefined behavior, not an error, and the buffer you get from alloc must be released by hand with free. Use an Array when you want checked access and automatic memory, and a raw pointer when the loop is what matters.
