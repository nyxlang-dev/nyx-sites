Option<T> es la manera que tiene Nyx de expresar un valor que puede estar presente o no. En lugar de retornar un valor centinela como -1 o arriesgarse a un puntero nulo, las funciones retornan Option.Some(value) en caso de éxito u Option.None cuando no hay nada que retornar.

encontrado: 10 no encontrado if let Some: valor es 7

Option<T> es un enum genérico con dos variantes: Option.Some(value) envuelve un valor existente de tipo T, y Option.None señala su ausencia. Como forma parte del prelude, no necesitas importarlo — siempre está disponible. Este patrón elimina toda una clase de bugs relacionados con nulos al hacer explícita la opcionalidad en el sistema de tipos.

La función describe muestra un match exhaustivo sobre un Option. El compilador exige que se manejen ambos casos — olvidarse de Option.None es un error en tiempo de compilación. El caso Some usa desestructuración de patrones para vincular el valor interno directamente a v, que luego queda disponible en la expresión de ese caso.

if let Option.Some(v) = c es un atajo conciso para cuando solo te interesa el caso Some y quieres recurrir a una rama else para el caso None. Vincula v dentro del cuerpo del if sin la formalidad de una expresión match completa.
