With the per-event arena on (runNyxWasm(bytes, { arena: true })) everything a handler allocates is thrown away when the event ends. A String or Array built in one event and stored in a global would be read by the next event as recycled memory — silently, with no error. arena_persist(x) copies the value into the persistent region first, so what you keep on purpose survives and everything else is still reclaimed.

It accepts a String or an Array of String, int, float and bool — including arrays of those, so a ticket line with its modifiers is copied whole, as g_ticket shows. A struct, a Map, an Fn or an Array<Struct> is a compile error (NYX1039): at run time they do not carry a description of what they contain, so persist their fields one by one and rebuild the value where you use it.

arena_persist is a builtin, so nothing is imported for it, and on a native build it is the identity function (there is no arena). That is what lets the logic around it run under nyx test. arena_stats(), from std/wasm_mem and wasm-only, returns the persistent bytes and the current turn's, which is how a long-lived page watches for unbounded growth. This is a browser recipe — it is built with nyx build --target wasm32-wasi and the page calls its exports — so the output above is illustrative.
