if let es una construcción compacta de pattern matching que combina una verificación condicional y un binding en una sola expresión. Es especialmente útil cuando solo importa una variante de un enum y se quiere evitar la verbosidad de un match completo.

find_even recorre un array a partir de un índice dado y retorna el primer número par envuelto en Option.Some, o Option.None si no se encuentra ninguno. Este es un patrón típico para funciones de búsqueda: el tipo de retorno comunica "encontrado o no encontrado" a través del sistema de tipos en lugar de un valor centinela mágico.

La sintaxis if let Option.Some(v) = a evalúa el patrón Option.Some(v) contra el valor a. Si coincide, el valor interno se asigna a v y el cuerpo del if se ejecuta con v en scope. Si el patrón no coincide (es decir, el valor es Option.None), se ejecuta en cambio la rama else. Esto es exactamente equivalente a un match de dos brazos pero encaja de forma más natural en código de estilo imperativo.

La tercera llamada usa un array puramente impar para demostrar que se toma la rama else. Nótese que cada bloque if let introduce un binding v nuevo cuyo scope está limitado a ese bloque — no hay riesgo de que el binding del primer bloque se filtre al segundo o al tercero.
