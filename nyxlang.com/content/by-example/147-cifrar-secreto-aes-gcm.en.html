An ERP stores each customer's mail-server password so it can send invoices on their behalf. It must be able to read the password in the clear, but a database dump must not reveal it. The password is encrypted with an installation key that lives outside the database (a file with mode 600). try_aes256gcm_seal(key, text, aad) returns a random nonce, the ciphertext and the tag as one value, which is turned into base64 for a text column.

The encryption is authenticated: try_aes256gcm_open(key, sealed, aad) checks the tag before returning anything. The aad is not encrypted but is bound to the value; with the record id, one customer's secret does not open in another's row and the attempt gives an Err with code 74. The error message never includes the secret.
