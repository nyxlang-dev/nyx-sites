std/barcode is Nyx code, no C: the same program that runs on the server compiles to wasm32-wasi and runs offline on a point-of-sale box. It returns DATA, never a drawing: qr_matrix gives the module grid, code128_widths and ean13_widths give the alternating bar/space widths in modules. Each caller paints that as it needs — terminal text, an SVG for a ticket, or a bar count for a thermal printer — this recipe shows all three.

qr_matrix(text, ecc) picks the version (size) and mask on its own and only fails when the payload does not fit — a Result.Err, never a QR that a reader cannot decode. QrEcc.M recovers about 15% of damaged modules; QrEcc.H (about 30%) is for thermal paper that fades. The matrix carries no quiet zone: the 4-module margin a scanner needs around it is the caller's job, drawn here in qr_as_text.

code128_widths chooses the character set by itself: "C1-" goes out in set B (letters) and "000123" switches to set C, which packs a digit pair per symbol — half the width of the same run in B. The widths are barred and spaced alternately starting with a bar, which is what lets code128_svg emit one <rect> per even-indexed width and skip the spaces.

ean13_widths takes either 12 digits, and computes the check digit, or 13, and validates it — the second call here deliberately gets the wrong one back as an Err naming both the digit it found and the one it expected, instead of silently accepting a mistyped barcode.
