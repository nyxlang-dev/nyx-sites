nyx test --coverage (needs llvm-profdata, the same major version as clang) prints, after the run's summary, which functions in src/ no test called — something a runner that only says pass/fail per file cannot answer. This recipe demonstrates the LANGUAGE guarantee that report leans on: two homonymous functions in different modules never mix when measured. The flag itself belongs to the tool, not to something callable from a Nyx program.

calc.valor() = 1, aux.valor() = 2

calc_valor and aux_valor play the role of two homonymous valor() functions in different modules (src/calc.nx and src/aux.nx in a real project). The assert confirms that calling one module's never calls the other's — the guarantee the whole per-module coverage report depends on.

Against a real sample project, nyx test --coverage prints something like this after the summary: src/calc.nx: 3/5 llamadas with the list of uncalled lines, src/otro.nx: 0/1 llamadas (ninguna prueba lo importa), and a total. It counts functions only, not lines or branches; a function that runs inside a spawn still counts as called, and a test file that crashes or times out leaves its functions marked "no data", never "not called" — killing a test with --timeout cannot skew the report.

Measured on a real 93-file suite: +13.6% time (105m23s → 119m41s). --coverage=lcov also writes target/coverage.lcov for an external viewer.
