arr.join(sep) convierte cada casilla por su etiqueta: enteros, floats y booleanos salen igual que con to_string(). La interpolación, "${x}", y String + x usan el tipo Nyx del operando, no el tipo de máquina que hay debajo.

1, 2, 3 u8=65 char=A literal=z

Un u8 y un char son el mismo byte para la máquina, pero no para el lenguaje: "${b}" con b: u8 = 65 da 65, y el char da A. Para ver el carácter de un byte, se guarda en una variable char. Un literal char se interpola como su carácter.

Un Array o un Map no tienen conversión a texto. Dentro de una lista, join aborta con un mensaje que nombra la casilla; interpolar uno es un error de compilación, NYX1010, con la pista de recorrerlo o interpolar sus partes.
