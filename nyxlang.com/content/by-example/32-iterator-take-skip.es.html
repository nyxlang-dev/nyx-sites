take(n) limita un iterador a sus primeros n elementos, mientras que skip(n) descarta los primeros n y produce el resto. Juntos forman los bloques básicos de ventanas deslizantes, recortes y paginación sobre cualquier secuencia.

skip(2): 8 elementos take(3): 3 elementos [0]=1 [2]=3 skip(2).take(3): 3 elementos 3 4 5 pagina 2 (skip 3, take 3): 3 elementos

skip(2) sobre un array de 10 elementos produce los elementos en las posiciones 2 a 9, dando 8 elementos. take(3) detiene el iterador después de los primeros 3 elementos, produciendo [1, 2, 3] — así que [0] es 1 y [2] es 3.

Encadenar skip(2).take(3) primero descarta dos elementos, y luego limita el resto a tres — produciendo [3, 4, 5]. Este es el patrón clásico de ventana deslizante. El orden importa: take(3).skip(2) en cambio daría un único elemento.

El ejemplo de paginación al final muestra un uso real directo: para obtener la página P de tamaño N, se escribe .skip((P-1) * N).take(N). Ambos adaptadores son perezosos — no se asigna ningún elemento hasta que se llama a .collect().
