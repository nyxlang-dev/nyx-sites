A defer runs when control LEAVES THE BLOCK where it is written: by falling off the end, by return, by ? on an Err, by break or by continue. Up to 0.35.0 only the one at the top level of a function ran, and a block's defer was dropped silently; from 0.36 on it runs.

ok

Four things are shown. A defer inside a loop releases something on EVERY iteration. A defer inside an if with an early return still runs. The order is LIFO within a block and from the inside out between nested blocks. And the body of a defer sees the values AT EXIT, not at the moment it was declared. The program prints ok when every one of those holds.

The limit: a throw that leaves the function does not run its defers. If you need the cleanup, use Result and ?.
