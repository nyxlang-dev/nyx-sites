Struct tupla, notación científica y enteros angostos

Un struct tupla tiene campos posicionales: struct Punto(int, int) se construye como Punto(3, 4) y se lee con p.0 y p.1 (o p._0, p._1). Sirve para un newtype como Metros(float), o para un par que merece nombre propio.

// Nyx by Example: struct tupla, notación científica y enteros angostos.
//
// Un struct tupla tiene campos posicionales: se construye como una llamada y
// se lee con `.0`, `.1` (o `._0`, `._1`). Sirve para un newtype (`Metros(float)`)
// o para un par con nombre propio.
//
// Los float aceptan exponente (`1.5e3`). Un entero angosto (`u8`, `i32`…)
// mezclado con un `int` da un `int`; al guardarlo de vuelta se trunca.
struct Metros(float)
struct Punto(int, int)

fn distancia2(a: Punto, b: Punto) -> int {
    let dx = a.0 - b.0
    let dy = a.1 - b.1
    return dx * dx + dy * dy
}

fn main() -> int {
    let p = Punto(3, 4)
    let origen = Punto(0, 0)
    print(distancia2(p, origen))

    let luz = Metros(2.998e8)
    print(luz.0 / 1.0e3)

    let b: u8 = 250
    let n = b + 10
    print(n)
    let de_vuelta: u8 = b + 10
    print(de_vuelta)
    return 0
}
Salidastdout
25
299800.0
260
4

Cómo funciona

Los literales float aceptan exponente: 2.998e8, 1.0e3. La tercera línea de la salida es la velocidad de la luz en kilómetros por segundo.

Un entero angosto (u8, i32 y los demás) mezclado con un int se ensancha a int: b + 10 con b: u8 = 250 es 260. Al guardarlo de vuelta en un u8 se trunca a 4. Dos operandos del mismo tipo angosto se quedan en su ancho y envuelven ahí.

Construir un struct tupla con la cantidad equivocada de argumentos es NYX1006; llamar como si lo fuera a un struct de campos con nombre es NYX1007.
