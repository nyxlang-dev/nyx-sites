Un buffer de bytes con un puntero crudo

Para recorrer muchos píxeles o bytes en un bucle caliente, un Array paga una llamada al runtime por acceso. Un puntero crudo a escalar (*u8, *int) indexa directo en memoria: p[i] lee o escribe el elemento i, a i * sizeof(T) bytes del inicio, como en C. No hay chequeo de límites, por eso vive dentro de unsafe.

// Nyx by Example: un buffer de bytes con un puntero crudo.
//
// Para recorrer muchos píxeles o bytes en un bucle caliente, un `Array`
// paga una llamada al runtime por acceso. Un puntero crudo (`*u8`, `*int`)
// indexa directo en memoria: `p[i]` lee o escribe el elemento i, a
// i * sizeof(T) bytes del inicio, sin chequeo de límites (como en C). Por
// eso vive dentro de `unsafe`.
//
// Un `u8` leído se ensancha SIN signo: 250 sigue siendo 250 al pasarlo a
// int. Y `*p as int` es `(*p) as int`: el `as` se aplica al valor leído.

fn main() -> int {
    unsafe {
        // Una fila de 6 píxeles en escala de grises.
        let fila: *u8 = alloc<u8>(6)
        var i = 0
        while i < 6 {
            fila[i] = 200 + i * 10    // 200, 210, ..., 250
            i = i + 1
        }

        // Invertir cada píxel y sumar el brillo total.
        var total = 0
        i = 0
        while i < 6 {
            let v: int = fila[i] as int
            fila[i] = 255 - v
            total = total + v
            i = i + 1
        }
        println("brillo original: " + int_to_string(total))
        println("primer píxel invertido: " + int_to_string(*fila as int))

        // Lo mismo con enteros de 64 bits.
        var acum: *int = alloc<int>(3)
        acum[0] = 1
        acum[1] = 2
        acum[2] = acum[0] + acum[1]
        println("acum[2] = " + int_to_string(acum[2]))

        free(fila)
        free(acum)
    }
    return 0
}
Salidastdout
brillo original: 1350
primer píxel invertido: 55
acum[2] = 3

Cómo funciona

El programa reserva una fila de 6 píxeles en escala de grises con alloc<u8>(6) y la llena con fila[i] = 200 + i * 10 (200, 210, hasta 250). Un segundo bucle lee cada píxel como int, escribe 255 - v para invertirlo y suma el brillo original, que da 1350. Luego hace lo mismo con enteros de 64 bits: un *int de alloc<int>(3), donde acum[2] es la suma de las dos primeras celdas. Los dos buffers se liberan con free.

Dos detalles que conviene conocer. Un u8 leído se ensancha sin signo: 250 sigue siendo 250 al convertirlo con as int, nunca un número negativo. Y *fila as int significa (*fila) as int: el as se aplica al valor leído, por eso el primer píxel invertido imprime 55 (255 - 200).

Límites: el puntero no lleva longitud, así que leer o escribir más allá del tamaño reservado es comportamiento indefinido, no un error, y el buffer que da alloc se libera a mano con free. Se usa un Array cuando se quiere acceso verificado y memoria automática, y un puntero crudo cuando lo que importa es el bucle.
