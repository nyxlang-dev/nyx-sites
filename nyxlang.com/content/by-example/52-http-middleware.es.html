El framework std/web ofrece una API estilo Flask para construir aplicaciones web. App guarda las rutas y el middleware, app_get/app_post registran los handlers de ruta, y app_use agrega middleware que se ejecuta antes de cada petición. El middleware incluido de fábrica incluye mw_logging y mw_cors.

app configured with 2 routes and 2 middlewares routes: GET / and GET /api/status middleware: logging + CORS

app_new() crea una aplicación vacía. Los handlers de ruta reciben una struct Request (con los campos: method, path, query, headers_flat, body) y retornan una struct Response. Funciones auxiliares como response_new y response_json crean respuestas con los headers apropiados.

mw_logging registra el método, la ruta, el status y la latencia de cada petición. mw_cors maneja las peticiones OPTIONS de preflight y agrega los headers CORS. Puedes configurar CORS con cors_configure(origin, methods, headers).

En producción, pasa la app a serve_app(app, port, workers) de nyx-serve para levantar un servidor HTTP multi-hilo. Así están construidos los cuatro sitios de nyxlang.com.
