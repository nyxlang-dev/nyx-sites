std/toml parsea strings de configuración TOML en un Map plano con claves en notación de punto. TOML es el formato de configuración que usa nyx.toml (el manifiesto del package manager) y cualquier servicio que guarde sus ajustes en un archivo .toml.

host: localhost port: 8080 debug mode enabled db: /var/data/app.db

toml_parse lee un string TOML y devuelve un Map<String> donde las claves de sección usan notación de punto: [server] + host = "localhost" se convierte en "server.host" → "localhost". Todos los valores se almacenan internamente como strings.

Los accesores tipados — toml_get (string), toml_get_int, toml_get_bool — convierten desde la representación en string y aceptan un valor por defecto si falta la clave. toml_has verifica si una clave existe sin leer su valor.

Este es el mismo parser que usa nyx build para leer los manifiestos de proyecto nyx.toml, y el que usarías cuando un servidor tiene que cargar su tabla de rutas desde un archivo .toml al arrancar.
