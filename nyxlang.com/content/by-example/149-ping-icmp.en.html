A network monitor asks whether a machine answers, and how fast. Before, you had to run ping -c 1 with exec() and parse output that changes from one system to another. try_ping(host, timeout_ms) returns the result with the resolved IP (r.ip) and the time in microseconds (r.rtt_us).

127.0.0.1 (127.0.0.1): responde en 41 µs localhost (127.0.0.1): responde en 9 µs

It works without privileges where the system allows it: Linux with net.ipv4.ping_group_range open (as on Debian and Ubuntu). Otherwise the error has kind equal to "permission". A machine not answering does not mean it is down: many firewalls drop ICMP. The times in the example depend on the machine.
