An ERP hands over the month's purchase ledger in Excel. std/xlsx writes a genuine .xlsx — a zip with XML inside, in pure Nyx, so it runs the same on the server and on wasm32-wasi — that Excel, LibreOffice and openpyxl all open.

libro: 3375 bytes, empieza con PK para escribirlo: nyx run -- libro.xlsx

A sheet is a list of rows of cells, built with xlsx_sheet_new and row(). Cells have one constructor per type: xlsx_text, xlsx_number(value, decimals), xlsx_int, xlsx_date("YYYY-MM-DD"), xlsx_bool, xlsx_blank and xlsx_bold. On top of that come column widths (col_width), merged cells (merge), a header that stays put on scroll (freeze), an autofilter over the table, and amounts with a thousands separator through xlsx_number_fmt and "#,##0.00".

The total is calculated in the program: formulas are NOT written, the value is. And mistakes — a repeated sheet name, an invalid date — surface from xlsx_write as an Err, not earlier. Run it with nyx run -- libro.xlsx to write the file; with no argument it only reports the size, which is what you see above.
