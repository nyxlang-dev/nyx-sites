Guardar cifrado un secreto que hay que volver a usar

Un ERP guarda la contraseña del servidor de correo de cada cliente para enviar facturas en su nombre. Debe poder leerla en claro, pero un volcado de la base no debe revelarla. Se cifra con una llave de la instalación que vive fuera de la base (un archivo con permisos 600). try_aes256gcm_seal(llave, texto, aad) devuelve nonce al azar, cifrado y etiqueta en un solo valor, que se pasa a base64 para una columna de texto.

// Nyx by Example: guardar cifrado un secreto que hay que volver a usar (AES-256-GCM).
//
// El caso real: un ERP guarda la contraseña del servidor de correo de cada
// cliente para mandar facturas en su nombre. Tiene que poder leerla en claro,
// pero un volcado de la base no debe revelarla. Se cifra con una llave de la
// instalación que vive FUERA de la base (un archivo con permisos 600).
//
// std/crypto hace cifrado AUTENTICADO: si alguien altera el valor guardado, o
// lo copia al registro de otro cliente, abrirlo da Err en vez de basura.
//   - try_aes256gcm_seal(llave, texto, aad): nonce al azar ‖ cifrado ‖ etiqueta;
//   - try_aes256gcm_open(llave, sellado, aad): la inversa.
// `aad` no se cifra pero queda atado al valor: con el id del registro, el
// secreto de un cliente no abre en la fila de otro.

import "std/crypto"
import "std/error"
import "std/base64"

fn main() -> int {
    // En un programa real: let llave: String = read_file("/etc/miapp/llave")
    // (32 bytes crudos, generados UNA vez con csprng_bytes(32) y guardados).
    let llave: String = csprng_bytes(32)

    // ── Guardar: sellar y pasar a base64 para una columna de texto ──────
    var columna: String = ""
    match try_aes256gcm_seal(llave, "clave-smtp-del-cliente", "smtp:cliente-42") {
        Result.Ok(s) => { columna = base64_encode(s) }
        Result.Err(e) => { println("no se pudo cifrar: " + error_to_string(e)); return 1 }
    }
    println("guardado: " + int_to_string(columna.length()) + " caracteres base64")

    // ── Leer: el mismo aad que al guardar ───────────────────────────────
    match try_aes256gcm_open(llave, base64_decode(columna), "smtp:cliente-42") {
        Result.Ok(clave) => { println("leído: " + clave) }
        Result.Err(e) => { println("no se pudo leer: " + error_to_string(e)); return 1 }
    }

    // ── El mismo valor copiado al registro de otro cliente no abre ──────
    match try_aes256gcm_open(llave, base64_decode(columna), "smtp:cliente-43") {
        Result.Ok(_c) => { println("ERROR: abrió con otro aad"); return 1 }
        Result.Err(e) => {
            // code 74: no se autentica. El mensaje nunca trae la clave.
            println("otro cliente: rechazado (code " + int_to_string(e.code) + ")")
        }
    }
    return 0
}
Salidastdout
guardado: 68 caracteres base64
leído: clave-smtp-del-cliente
otro cliente: rechazado (code 74)

Cómo funciona

El cifrado es autenticado: try_aes256gcm_open(llave, sellado, aad) verifica la etiqueta antes de devolver nada. El aad no se cifra pero queda atado al valor; con el id del registro, el secreto de un cliente no abre en la fila de otro y el intento da un Err con código 74. El mensaje del error nunca incluye la clave.
