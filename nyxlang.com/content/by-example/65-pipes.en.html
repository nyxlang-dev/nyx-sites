try_spawn_pipeline([argv1, argv2, ...], opts) runs printf … | sort | head -n 2 without a shell. It creates the intermediate pipes and closes the parent's ends in time; if the parent kept one open, the next command in the chain would never see end-of-file. opts.stdin feeds the first command and opts.stdout belongs to the last one.

exit code: 0 lines: 2

It returns the children in order. With opts.stdout = Stdio.Pipe, try_child_collect on the last child reads its output to the end and waits for it; the others are waited for with try_child_wait so none is left as a zombie. If one command cannot be launched, the ones already started are killed and waited for, and the error says which step failed in e.stage.

The raw builtins pipe_new, fork, dup2 and execvp, which this recipe used before, are still available on posix.
