Check a program exists before launching it

Before launching an external tool it is useful to know whether it is installed, to print your own "git is missing" message or to pin its path once. find_program(name) from std/process returns Option<String> with the path try_spawn would execute, using the same search: PATH (on Windows also PATHEXT, and never the current directory).

// Nyx by Example: saber si un programa existe ANTES de lanzarlo, con std/process.
//
//     find_program(name) -> Option<String>
//
// Devuelve la ruta que try_spawn ejecutaría para `name`, con la MISMA búsqueda:
// PATH (en Windows también PATHEXT, y nunca el directorio actual). Sirve para
// avisar "falta git" con un mensaje propio, o para fijar la ruta una vez.
//
//   - None si no está, no es ejecutable, es un directorio o el nombre es vacío.
//   - En Windows, un programa que solo existe como .bat/.cmd da None: try_spawn
//     lo rechaza (usa std/exec para esos).
//   - Un nombre con separador ("./tool", "/usr/bin/sh") se mira tal cual, sin PATH.

import "std/process"

fn main() -> int {
    // `sh` existe en cualquier Linux. La ruta absoluta varía por máquina, así
    // que solo se muestra si se encontró.
    match find_program("sh") {
        Option.Some(p) => { print("sh: encontrado") }
        Option.None => { print("sh: no está") }
    }
    // Un programa inexistente da None: no hay error que atrapar.
    match find_program("nyx-no-such-program-xyz") {
        Option.Some(p) => { print("inexistente: " + p) }
        Option.None => { print("inexistente: None") }
    }
    // Un directorio no es un programa.
    match find_program("/") {
        Option.Some(p) => { print("directorio: " + p) }
        Option.None => { print("directorio: None") }
    }
    return 0
}
Outputstdout
sh: encontrado
inexistente: None
directorio: None

How it works

The example matches three cases. sh exists on any Linux, so it gives Some; the absolute path varies per machine, which is why the program only says it was found. A name that does not exist gives None: there is no error to catch. A directory such as / is not a program, so it also gives None. None also covers a file that is not executable and an empty name.

Limits: a name with a separator (./tool, /usr/bin/sh) is checked as given, without searching PATH. On Windows, a program that exists only as .bat or .cmd gives None, because try_spawn rejects those; use std/exec for them.
