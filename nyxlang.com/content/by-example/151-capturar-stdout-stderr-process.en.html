try_spawn(argv, opts) starts the child with each stream as a Stdio (inherited, null, pipe, file or fd). argv is an Array, so there is no shell: no quotes, no *, no $VAR to inject. With stdout and stderr on Stdio.Pipe, try_child_collect drains both at once and waits for the child, returning ChildOutput { stdout, stderr, code }.

A program that does not exist fails at launch with Err of kind not_found: there is no child that exits with 127. Reading "all of stdout, then stderr" can deadlock if the child fills the stderr pipe meanwhile; try_child_collect avoids it. Calls block the thread: with many children, use one spawn per child. On Windows a .bat or .cmd is rejected with invalid, and try_child_signal exists only on posix. The raw fork/execvp builtins remain available on posix.
