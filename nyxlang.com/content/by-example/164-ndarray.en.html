import "std/ndarray" gives NDArray: an array of float with one or more dimensions over a contiguous buffer that the garbage collector manages, with the kernels written in Nyx. The recipe walks through the essentials: constructors, shape, access, operators, scalars, reductions, matmul and the round trip through an Array<float>.

Three limits are worth knowing up front. The operators + - * / work only between two arrays of the same shape, with no broadcasting; a scalar goes through a method (a.add_scalar(2.0), a.mul_scalar(2.0)), and a * 2.0 is a compile error. There is no a[i, j]: reads and writes go through get, get2, set and set2. And passing an NDArray to a function shares its buffer; copy() makes a separate one.

Speed needs nyx build --release; without it the kernels run several times slower. Compiled that way it ties or beats numpy on elementwise operations and reductions, and wins on small arrays, where numpy pays a fixed cost per call. On matrix multiplication numpy, which calls BLAS, is still several times faster. The measured table, with the machine and the method, is in the std/ndarray section of docs/SPEC.md in the repository.
