El módulo std/regex envuelve expresiones regulares extendidas POSIX. Tres funciones cubren las operaciones más comunes: probar si un patrón coincide, extraer la primera coincidencia y reemplazar coincidencias en una cadena. Los patrones siguen la sintaxis estándar POSIX ERE.

Email: alice@example.com -> 1 Email: no-es-email -> 0 Email: bob.dev@nyx-lang.org -> 1 Version encontrada: 0.12.0 Sin espacios dobles: Hola mundo Nyx Sin HTML: nyx es rapido

regex_is_match(str, pattern) devuelve un bool (representado como 1/0 al imprimirse vía int_to_string) que indica si el patrón coincide en algún punto de la cadena. Anclar con ^ y $ obliga a que la coincidencia sea sobre la cadena completa, algo esencial para validar entradas como en el ejemplo del email.

regex_match(str, pattern) devuelve la primera subcadena que coincide con el patrón, o una cadena vacía si no hay coincidencia. Es útil para tareas de extracción, como parsear números de versión, fechas o identificadores dentro de un texto más grande.

regex_replace sustituye la primera coincidencia por una cadena de reemplazo, mientras que regex_replace_all reemplaza todas las coincidencias no solapadas. El ejemplo que elimina etiquetas HTML usa el patrón <[^>]+> para hacer coincidir cualquier etiqueta HTML completa y la reemplaza por una cadena vacía, dejando solo el contenido de texto.
