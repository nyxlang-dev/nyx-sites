Un Map almacena pares clave-valor con búsqueda rápida por clave. Los maps se crean con Map.new() y soportan inserción, recuperación, prueba de pertenencia y enumeración de claves.

paises: 3 Capital de Francia: Paris tiene Argentina: si tiene Brasil: no claves (3): Francia Japon Argentina

Los maps en Nyx se crean con Map.new() — no existe una sintaxis de map literal (sería ambigua con las expresiones de bloque). Los maps deben declararse con var si se pretende insertar o modificar entradas después de la creación.

El método .insert(key, value) agrega o actualiza un par clave-valor. .get(key) obtiene el valor de una clave, devolviendo el valor almacenado como String (o el tipo correspondiente). Si la clave no existe, el comportamiento es indefinido — usa .has(key) primero para verificar la pertenencia.

.has(key) devuelve un bool, y en Nyx un bool no es un int: pasarlo directo a int_to_string no compila, así que la receta lo lleva a texto con el pequeño helper si_no. .size() devuelve la cantidad de entradas actualmente en el map.

.keys() devuelve un Array con todas las claves del map, y el orden de iteración de un hash map no es el de inserción. Un Array tampoco lleva consigo el tipo de sus elementos, así que el cuerpo del bucle liga cada clave con let clave: String = k antes de imprimirla — sin esa anotación la concatenación emitiría la dirección de la clave en vez de su texto.
