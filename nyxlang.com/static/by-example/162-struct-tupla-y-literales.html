162 / Types and patterns

Tuple structs, scientific notation and narrow integers

A tuple struct has positional fields: struct Punto(int, int) is built as Punto(3, 4) and read with p.0 and p.1 (or p._0, p._1). It fits a newtype such as Metros(float), or a pair that deserves its own name.

162-struct-tupla-y-literales.nxSource →
// Nyx by Example: struct tupla, notación científica y enteros angostos.
//
// Un struct tupla tiene campos posicionales: se construye como una llamada y
// se lee con `.0`, `.1` (o `._0`, `._1`). Sirve para un newtype (`Metros(float)`)
// o para un par con nombre propio.
//
// Los float aceptan exponente (`1.5e3`). Un entero angosto (`u8`, `i32`…)
// mezclado con un `int` da un `int`; al guardarlo de vuelta se trunca.
struct Metros(float)
struct Punto(int, int)

fn distancia2(a: Punto, b: Punto) -> int {
    let dx = a.0 - b.0
    let dy = a.1 - b.1
    return dx * dx + dy * dy
}

fn main() -> int {
    let p = Punto(3, 4)
    let origen = Punto(0, 0)
    print(distancia2(p, origen))

    let luz = Metros(2.998e8)
    print(luz.0 / 1.0e3)

    let b: u8 = 250
    let n = b + 10
    print(n)
    let de_vuelta: u8 = b + 10
    print(de_vuelta)
    return 0
}

How it works

Float literals accept an exponent: 2.998e8, 1.0e3. The third line of the output is the speed of light in kilometers per second.

A narrow integer (u8, i32 and the rest) mixed with an int widens to int: b + 10 with b: u8 = 250 is 260. Storing it back in a u8 truncates it to 4. Two operands of the same narrow type stay in their width and wrap there.

Building a tuple struct with the wrong number of arguments is NYX1006; calling a struct with named fields as if it were one is NYX1007.
