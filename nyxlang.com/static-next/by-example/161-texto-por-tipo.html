Text by the real type: join and interpolation

arr.join(sep) converts each slot by its tag: integers, floats and booleans come out the same as with to_string(). Interpolation, "${x}", and String + x use the Nyx type of the operand, not the machine type underneath.

161-texto-por-tipo.nxSource →
// Nyx by Example: convertir a texto por el tipo real (join e interpolación).
//
// `join` convierte cada casilla por su tag: enteros, floats y bool salen igual
// que con `to_string()`. Un Array o un Map dentro de la lista aborta con un
// mensaje claro (no tienen conversión a String).
//
// La interpolación usa el tipo Nyx del operando: un `u8` da el NÚMERO y un
// `char` da el carácter. Para ver el carácter de un byte, conviértelo a `char`.
fn main() -> int {
    let nums = [1, 2, 3]
    print(nums.join(", "))

    let b: u8 = 65
    let c: char = 'A'
    print("u8=${b} char=${c}")
    print("literal=${'z'}")
    return 0
}
Outputstdout
1, 2, 3
u8=65 char=A
literal=z

How it works

A u8 and a char are the same byte to the machine, but not to the language: "${b}" with b: u8 = 65 gives 65, and the char gives A. To see the character of a byte, store it in a char variable. A char literal interpolates as its character.

An Array or a Map has no conversion to text. Inside a list, join aborts with a message that names the slot; interpolating one is a compile error, NYX1010, with the hint to walk it or interpolate its parts.
